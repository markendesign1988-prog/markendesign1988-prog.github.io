官網內容管理

登入採用 GitHub 個人存取權杖。權杖只保存在目前開啟的頁面記憶體，不會寫入官網、儲存至瀏覽器或傳給第三方。請勿把權杖傳給任何人。

請確認選擇的是實際發布官網的 Repository。若不是，請修改上方名稱。此後台不需要 Account 權限。

文字內容

圖片管理

可替換網站中的圖片。上傳圖片會放到所選 Repository 的 assets/admin/ 內，儲存時一起更新 HTML。大型圖片可能增加載入時間。

使用說明與安全事項

儲存會提交 index.html 及新圖片至 GitHub。GitHub Pages 部署可能需要數分鐘。若 Repository 設定了自訂部署流程，請確認其 Pages 發布來源。

建議將 Token 設定短期限、限定單一 Repository，且只開啟 Contents 的讀寫權限。使用完畢按「結束管理」或關閉頁面。
